## 📦 Краткое описание серверной части

- **Язык и фреймворк:** Node.js + Express.js
- **База данных:** PostgreSQL
- **ORM:** Sequelize
- **Email-отправка:** NodeSender
- **Загрузка файлов:** Cloudinary SDK, Imagekit (аватарки, изображения товаров)
- **Аутентификация:** JWT
